# Repo-Registry

Liste der vom Supervisor verwalteten Repositories. Trage hier jedes Repo ein,
das das Agenten-System betreuen soll.

> Hinweis: Damit ein Sub-Agent auf ein Repo zugreifen kann, muss es im
> Session-Scope liegen (ggf. zur Session hinzufügen).

| Repo | Typ | Zuständige Agenten | Notizen |
|------|-----|--------------------|---------|
| `luccas1997/first_website` | Frontend | frontend-agent, review-agent | Dieses Repo (Supervisor + Beispiel-Webseite) |
| _… hinzufügen …_ | | | |

## Vorlage für neue Einträge

```
| owner/repo | Frontend/Backend/Full-Stack | <agenten> | <kurze Beschreibung> |
```
